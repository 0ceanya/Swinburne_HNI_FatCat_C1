# Swinburne_HNI_FatCat_C1

**SignGuard**: a key vault for a company's third-party credentials (digital signatures such as Viettel MySign, cloud root keys, API keys), locked by the Tide network through TideCloak. Each key has a permission level: the number of board members who must approve, in Tide's own window, before the network seals or unlocks it.

- How it works, how to run it, tests: [`tidecloak/app/README.md`](tidecloak/app/README.md)
